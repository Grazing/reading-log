# 书历

本地月历阅读记录，也可当作 Mac 桌面壁纸。

## 壁纸应用（推荐）

打开 `/Applications/书历.app`。窗口就是月历网页（不用 Safari）。顶栏可选显示器、自动更新壁纸、开机启动、设为壁纸。从源码安装：`macos/build.sh`；打安装包：`macos/package.sh` → `dist/书历.dmg`。

发给另一台 Mac 时若提示「已损坏」，多半是 Gatekeeper（当前仅 ad-hoc 签名、未公证），不是文件坏了。对方执行 `xattr -cr /Applications/书历.app`，或对应用右键 → 打开。

也可以双击 `start.command` 只开网页服务；日常请只用这个应用。

请不要只在 Cursor 对话里后台跑 `python3 app.py`：关掉对话后进程会被一起关掉。已在运行时再点一次 `start.command` 只会打开浏览器，不会杀服务。

数据存在本机 `~/.reading-log/`，不会上传。

## 手机随时查看（固定网址）

用 **ngrok** 把本机 `127.0.0.1:18766` 映射成固定 https 地址（免费账号自带一个不变域名）。数据仍在 Mac，手机打开的是同一套界面。

1. Mac 上照常开着「书历.app」（或 `start.command`）
2. 双击项目里的 `remote.command`
3. **首次**会打开浏览器拿 authtoken，粘贴进终端即可（只需一次）
4. 终端里会打印固定网址，并写入 `~/.reading-log/remote-url.txt`

之后每次只要 Mac 开着、隧道窗口没关，手机用同一地址就能看。关掉 `remote.command` 那个终端窗口即断开公网。

注意：知道网址的人都能打开；不要把地址发到公开场合。免费域名第一次打开可能有 ngrok 提示页，点 Visit Site 即可。

## 大我 B7（彩色墨水屏）

手机上的「书历」只做预览和壁纸。阅读记录仍在 Mac 的 `~/.reading-log/`。手机打开的月历、日志、卡片，是 Mac 上正在跑的这一份，颜色与 Mac 相同，不去灰。

1. Mac 上开着书历。同一 Wi-Fi 下手机用局域网地址（启动时会打印，也写在 `~/.reading-log/lan-url.txt`）。人在外面就填 ngrok 的 https 地址。
2. 安装 `dist/reading-log-b7.apk`。设置里填上面的地址，保存。
3. 月历页上的倍数、宽、高就是壁纸像素（横版或竖版也跟着这个选择）。点「更新壁纸」后在后台生成，不会切到书历，也不会放大预览。设置里需要允许「显示在其他应用的上层」。彩色 PNG 每次覆盖同一张：

```text
/storage/emulated/0/Pictures/书历/书历.png
```

4. 在大我的待机画面里选一次这张图。之后按设定的分钟数，或锁屏时，再覆盖这一张。
5. 若系统把这个应用去色，在大我控制中心把「书历」设为彩色。壁纸文件本身是彩色的。


## 月历

- 左上角日期，右上角当日阅读时长
- 格子里用淡彩色横条表示书；同一本书连续几天会连成一条
- 书名默认黑色、左对齐
- 右键横条可改横条颜色、书名颜色，或删除当天这条
- 每天最多 4 本；可设置「低于 x 分钟不计入」，默认 3 分钟
- 双击格子可手动添加记录

## 数据来源

**微信读书**：设置里扫码登录（或粘贴 Cookie）。打开月历时会自动同步。若本机已经登录过「阅读月历」壁纸工具，会复用 `~/.weread-calendar/session.json`。

**掌阅**：没有公开的日级阅读统计接口，不能扫码自动拉取。可以：

- 在「添加记录」里把来源选成掌阅
- 或在设置中导入 CSV（表头 `日期,书名,分钟`）

**手动**：同一入口，来源选「手动」。
