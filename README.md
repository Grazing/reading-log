# 书历

本地月历阅读记录，也可当作 Mac 桌面壁纸。

## 壁纸应用（推荐）

打开 `/Applications/书历.app`。窗口就是月历网页（不用 Safari）。顶栏可选显示器、自动更新壁纸、开机启动、设为壁纸。从源码安装：`macos/build.sh`；打安装包：`macos/package.sh` → `dist/书历.dmg`。

发给另一台 Mac 时若提示「已损坏」，多半是 Gatekeeper（当前仅 ad-hoc 签名、未公证），不是文件坏了。对方执行 `xattr -cr /Applications/书历.app`，或对应用右键 → 打开。

也可以双击 `start.command` 只开网页服务；日常请只用这个应用。

请不要只在 Cursor 对话里后台跑 `python3 app.py`：关掉对话后进程会被一起关掉。已在运行时再点一次 `start.command` 只会打开浏览器，不会杀服务。

数据存在本机 `~/.reading-log/`，不会上传。

## 月历

- 左上角日期，右上角当日阅读时长
- 格子里用淡彩色横条表示书；同一本书连续几天会连成一条
- 书名默认黑色、左对齐
- 右键横条可改横条颜色、书名颜色，或删除当天这条
- 每天最多 4 本；可设置「低于 x 分钟不计入」，默认 3 分钟
- 双击格子可手动添加记录

## 数据来源

**微信读书**：设置里扫码登录（或粘贴 Cookie）。打开月历时会自动同步。若本机已经登录过「阅读月历」壁纸工具，会复用 `~/.weread-calendar/session.json`。

**手动**：同一入口，来源选「手动」。
